# Platform Matrix

| Capability | x86_64 OS | ARM64/Raspberry Pi | ESP32 runtime |
|---|---|---|---|
| Bootable OS | Yes | Yes | Embedded firmware |
| Desktop | Planned | Planned | No |
| CLI | Yes | Yes | Yes |
| REST/API | Yes | Yes | Optional |
| Voice | Yes | Yes | Endpoint |
| Universal app manager | Yes | Yes | No |
| Containers | Yes | Yes | No |
| Attendance | Yes | Yes | Field endpoint |
| Transport | Yes | Yes | Field endpoint |
| Deterministic I/O | Hardware-dependent | GPIO/USB | Primary |
| OTA/system updates | Yes | Yes | Firmware OTA |
| Local AI | Yes | Yes | Limited/endpoint |

The matrix is a design contract, not a claim that every item is already implemented.
